# QMD Schedule Gantt Chart

An interactive Gantt chart for QMD members to schedule and track Institutional and Portfolio activities.

## Features
- Add, edit, and delete Institutional and Portfolio activities
- Full-year Gantt view with week columns
- Today marker
- Filter by activity type
- Data persists in browser localStorage

## Live Site
Once deployed, your site will be at:
`https://YOUR-USERNAME.github.io/qmd-gantt`

## Local Development
```bash
npm install
npm start
```

## Deployment
Pushes to `main` automatically deploy via GitHub Actions.
